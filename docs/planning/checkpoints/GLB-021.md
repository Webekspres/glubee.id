# Checkpoint GLB-021: Undangan dan persetujuan kontak darurat

Task: [GLB-021](https://app.clickup.com/t/86eyvadx7) · Jadwal 16-19 Oktober 2026 (dikerjakan 9 Okt) · Kebutuhan: FR-CONTACT-001, SRS §5/§7, CONSENT_AND_NOTICES §5-6

## Acceptance criteria (ClickUp)

1. Maksimal dua kontak aktif/pending terjaga termasuk request bersamaan; undangan diterima/ditolak tanpa akun.
2. Token hash sekali pakai, expiry, receipt versi dan batas akses diuji; kontak belum setuju tidak menerima data kesehatan.

## Keputusan desain

| Topik | Keputusan | Alasan |
|---|---|---|
| Batas dua kontak | Trigger lama `enforce_contact_limit` (advisory lock per pengguna) untuk insert dan perubahan state; berlaku juga saat expired → pending. | Race-safe tanpa kode baru. |
| Token | 32 byte acak, base64url; DB menyimpan SHA-256 di `contact_invitations` (RLS, tanpa grant klien). Sekali pakai (`used_at`), 7 hari (keputusan pengguna 9 Okt), undangan lama gugur saat kirim ulang. | AC token. |
| Token di URL | `/invite#<token>`; halaman membaca fragment, menghapusnya dari bilah alamat, mengirim token di body POST. | AGENTS §4: token undangan tidak boleh masuk log (nginx mencatat path + query, bukan fragment). |
| Email kontak | AES-256-GCM (`DATA_ENCRYPTION_KEY`) + HMAC untuk dedupe per pengguna. | SRS §11. |
| Persetujuan pengguna | `contact_share` (CNT-CONTACT-SHARE-001@0.2) dicatat sekali per versi sebelum undangan pertama. | CONSENT §5. |
| Keputusan kontak | `contact_consents` append-only dengan versi CNT-CONTACT-ACCEPT-001 yang ditampilkan; versi usang → `notice_outdated`. | AC receipt versi. |
| Isi email undangan | Nama pengundang + tautan + masa berlaku; tanpa nilai/kondisi kesehatan. Template lama yang menjanjikan alert nilai diganti. | AC: kontak belum setuju tidak menerima data kesehatan; alert masih PENDING. |
| Menolak | Kontak yang menolak tidak dapat diundang ulang oleh pengguna yang sama. | Mencegah undangan berulang ke orang yang sudah menolak. |
| Pengundang nonaktif | Undangan dianggap tidak berlaku bila akun pengundang tidak aktif. | Batas akses. |
| Aktivasi | `CONTACT_INVITES_ENABLED=false` sampai uji kolektif (kuota Brevo). | Keputusan pengguna 9 Okt. |
